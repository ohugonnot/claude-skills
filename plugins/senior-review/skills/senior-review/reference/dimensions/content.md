# content

- **contenu / prose** (cond., diff de texte : livre, documentation, article) : exactitude factuelle avec **source citée** (un chiffre normalisé se vérifie contre sa définition officielle, pas contre une paraphrase), parité des langues (même sens, retouche appliquée des deux côtés), définitions qui tiennent hors contexte (glossaire, extrait), règles de voix du projet (ce que son lint attrape déjà n'est pas re-flaggé), terme employé avant d'être défini, contradiction avec les phrases voisines.

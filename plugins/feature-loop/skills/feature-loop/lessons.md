# Feature-loop — meta-leçons cross-projet

Leçons sur *comment piloter la boucle*, valables sur tous les projets (pas les specs d'un projet — ça va dans `project_feature_loop_insights.md`). Chargé à l'init, complété en fin de run et par `learn`.

Format : `- **<titre>** : <règle actionnable> — *vu sur un run réel*`. Additif uniquement.

> ⚠️ **Mémoire LOCALE — ne pas publier le contenu réel.** Ce fichier s'accumule sur la machine et référence des projets/clients réels. Dans un repo PUBLIC il reste ce seed vide. Toute leçon versionnée publiquement doit être **anonymisée** (« un projet réel », « une intégration fournisseur » — jamais de nom client / vendor / branche / champ métier identifiant).

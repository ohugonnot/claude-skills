---
name: Préférence simplicité et non-redondance
description: Enlever plutôt qu'ajouter — ne pas dupliquer ce qui est déductible du code
type: feedback
---

Privilégier la suppression à l'ajout. Si une info est déductible du code ou d'un autre fichier, ne pas la dupliquer.

**Why:** Une doc qui répète le code se périme et ajoute du bruit ; la valeur est dans le non-déductible.

**How to apply:** Avant tout ajout de documentation, règle ou commentaire, vérifier si l'info existe déjà ailleurs ou est déductible. En cas de doute, ne pas ajouter.

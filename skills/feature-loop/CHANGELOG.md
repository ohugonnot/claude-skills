- **8.3.2** (2026-06) — Corrections issues d'un **run réel de couverture e2e** (un projet réel, 2 modules de recette Playwright + senior-review). Trois garde-fous/clarifications, tous additifs : (1) **Garde de périmètre post-impl** (§4.4a) : `git diff --name-only` vs le scope déclaré → edits hors scope (surtout code prod sur tâche test-only) flaggés et présentés à la mère AVANT le gate. Bump patch (gardes-fous + clarifications, pas de nouvelle étape).
